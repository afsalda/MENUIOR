# Brand assets

Put approved cafe logo and photos in this folder. Set `logo_url`, `hero_image`, and `hero_food_image` in the config or Settings CSV. Set each dish's `image` in Items to `brand/your-file.webp`.

The current wordmark is a typeset placeholder, not an official logo recreation. The favicon/app icon is a simple placeholder leaf. All photos in `demo/` are illustrative stock photos, not photos of Fress Trees or its actual dishes. Replace them before using the menu as an authoritative representation of the cafe.

Prefer WebP around 900px wide and under 150 KB. Keep filenames lowercase without spaces.
